# Get started with MultiMini

Put two windows in one view, then choose which one you control.

## 1. Add a window
Click Add on the left. Choose Window capture, pick the app you want, then confirm. Repeat to add a second window.

## 2. Arrange your view
Click a source to select it. Drag it in the preview to move it. Drag an edge handle to resize it.
Lower Opacity on the right if you want to see the layer underneath. Drag source rows up or down to change which one is on top.

## 3. Choose what you can control
Turn on the mouse icon beside each source you want to switch between. The eye icon shows or hides a source.

## 4. Start multitasking
Click Start multitasking. Right Ctrl switches the input target. Pause swaps the visual layers. These are separate actions: switching input does not change layer order.
Press End to return to Configure. You can also hover the exit button's position to reveal it and click it.

## Your shortcuts
Right Ctrl: switch input source.
Pause: swap visual layers.
End: leave multitask mode.
Insert: save a screenshot of the full view.
Ctrl+Shift+F12: select a screenshot region.
These are defaults. See Settings > Controls for your current shortcuts. Screenshot shortcuts only work while multitasking.

## Screenshots and Gallery
For a region, click and drag a rectangle. Choose Copy, Save, Copy and Save, or Cancel.
Open Gallery to view saved screenshots. Keep saves a picture indefinitely. Other pictures expire after seven days when cleanup runs. Copy puts the selected picture on your clipboard.

## Change a source or view
Double-click a source to change its capture target. F2 renames it. Delete removes it from MultiMini, without deleting the original image file.
Right-click a view tab to rename, duplicate or delete that view. At least one view must remain.

## Resize and align
Hold Shift while resizing to stretch a source. Hold Alt while dragging to turn off snapping temporarily. Reset size and position restores its transform.

## If something is not working
Blank capture: open the target app, then double-click its source and select the window again. Try windowed or borderless mode for games. Some protected content cannot be captured.
Wrong input target: check the source indicator and use your switch-input shortcut. Exit multitasking before sensitive actions.
Missing image: keep the original file available or select it again.
Recording a demonstration: use OBS Display Capture to follow both Configure and multitask mode. OBS Window Capture of Configure cannot follow the separate overlay window.

## Keyboard navigation
Tab and Shift+Tab move between controls. Space activates a focused button. Arrow keys change lists, sliders and page selections. Escape cancels shortcut recording. Use Page Down to read documents.

## Need more help?
Report a problem at https://github.com/MaDaAi/MultiMini/issues. Include your version and the steps that caused it. Remove private screenshots and personal information first: issues are public.
The other Help pages explain privacy, licensing and saved data. MultiMini processes capture locally; updates contact GitHub. Captured apps may use their own online services.
