# MultiMini Beta 0.06 Experimental — Windows x64

- Dark-by-default Light/Dark setting with contrast-aware control colors.
- View rename, duplication and deletion, retaining at least one view.
- Updated controller and visible/hidden eye icons; logo and Windows taskbar identity improvements.
- Gallery Copy action.
- Sidebar widths saved and restored on launch; improved divider hit areas and theme-safe dragging.
- Brief accent alignment guides and snapping while dragging; Alt bypasses snapping.
- Updated theme-aware view menu and removal of the preview corner decoration.
- Simplified source label to Game capture; controlled DX11 renderer clearly marked testing only.
- Version-independent README.

Includes bundled Java, Python and native components. Install over the existing installation to retain workspace and settings. Previous prereleases remain available for rollback.

Validation: Java/native builds, Python regressions, editor dragging/snapping checks, sidebar persistence checks, and rendered dark/light previews. Windows taskbar pin behavior and cross-PC capture/input performance still require wider live verification. Game capture remains WGC compatibility, not universal graphics API hooking; the controlled DX11 renderer is testing only. Secondary-monitor display input remains a reported limitation.
