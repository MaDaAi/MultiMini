# MultiMini Beta 0.04 Experimental — Windows x64

Windows-only experimental prerelease. Includes bundled Java and Python runtimes.

- Screenshot gallery with thumbnail previews, retention timers, Keep, Delete and file-location actions.
- Persistent local screenshot folder; Keep prevents automatic expiry.
- Updated agreement window and gallery dialogs.
- Restored large bold source heading and persistent accent styling for panel dividers and scrollbars.
- Circular translucent multitask exit button with an X, automatic hiding and reveal on input/layer changes or hover.

Install the EXE over your existing installation to preserve saved views, sources and settings. The repository remains private; download updates while signed in to an authorized GitHub account.

Game capture remains experimental. WGC game-window compatibility is not a universal graphics API hook. Compilation and existing automated checks do not establish compatibility with every game.
