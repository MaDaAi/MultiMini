# MultiMini v1.0.3 — Windows only

## Plain English
- Agreement and privacy pages are easier to read, with clearer headings and cleaner tabs.
- Selected tabs and selected text stay readable in dark and light mode.
- Update messages in Settings now match the app instead of using old-looking system message boxes.

## Detailed
- Added theme-aware agreement tabs with explicit selected-text painting and accent underlines.
- Rendered agreement/privacy documents with styled headings and body text in a scrollable text pane.
- Replaced agreement viewers and updater status/error prompts with themed resizable dialogs.
- Retained existing consent records, update verification and saved-data behavior. No terms were changed in this UI update.

## Installation
Windows x64 only. Update from the installed app or download the installer. Linux and macOS support are coming soon. Installer is unsigned. Existing installations will use their current UI for this update; the revised UI appears after installation.
