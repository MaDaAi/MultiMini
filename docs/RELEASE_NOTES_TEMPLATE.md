# MultiMini release notes template

Use these sections in each GitHub release body so the in-app updater can show both changelog views. Keep the summary factual and in everyday language; include only changes shipped in the release.

## Plain English
- Explain what changed for the user and why it helps.

## Detailed
- Describe the implementation changes, important fixes and known limitations.

The updater displays these sections as inert text. Do not include credentials, private screenshots or local user paths.
